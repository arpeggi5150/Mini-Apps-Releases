# Arcana Suite (Divination Suite) v0.1.0

One home for the divination apps. Open `index.html` in any browser. No build step, no account, no install.

- **Home screen:** one tile per module. Astrology App and Arcana open right inside the suite; the rest show as Coming soon.
- **Your profile, entered once:** name, birth date, birth time, birth place. Save up to 100 charts (yours and other people's). Everything stays on your device.
- **Shared settings:** Classical / Modern, Tropical / Sidereal (Tropical by default), house system. Red Letters and canon filters are for the Bible app when it arrives.

The suite opens the apps from their own folders next to it (`../astrology-app/`, `../arcana-app/`), so keep this repo's folders together. Each app also works on its own.
